Rekon

dev.rekonops.rekon is an OpenUPM Unity package. Bug reporting infrastructure for Unity game dev teams. Auto-capture video/screenshots/logs from play mode, then route them to a web dashboard and Jira.

Install this package from the OpenUPM scoped registry with the instructions on this page, or use openupm-cli to update Packages/manifest.json.

Repository: https://github.com/RekonOps/Rekon-unity.

Owner: RekonOps.
